はじめる前に

健康に関する情報を扱います

排便・服薬・体調の記録は、法律上とくに配慮が必要な個人情報です。ご本人の同意をいただいたうえでお預かりします。

お預かりするもの

排便・服薬・体調スコア・メモ・在宅／施設の別の記録。LINE通知を使う場合は通知先の識別子。

何に使うか

記録の保存・表示・PDF出力、LINEでの記録確認通知、不具合対応のみに使います。

外部への提供

ご本人の同意なく第三者へ提供しません。保存には Amazon Web Services を使います。

いつでもやめられます

記録は1日ずつ削除できます。「データの管理」からすべて削除することもできます。

利用統計は既定でオフ

所要時間だけを送る任意の統計は、設定画面でオンにしない限り送信しません。記録の中身は送りません。

同意しない場合

同意されなくても、不利益はありません。
